# 定位：纯探索（explore），不成文

本件只做写作的**探索阶段**：通过对话式追问持续采访用户，把一切可能活到成文的**碎片（fragments）**追出来、攒进一个文件，全程不承诺任何结构。一句话分工：本件管 explore 攒料，write-beats / write-shape 管 exploit 成文；当对话转向「这篇文章怎么组织」时，本件就到边界了。

「对话式追问」：围绕用户想写的话题，不断发问、追问、请他举例子、讲细节、说原话，直到有东西可写。不需要仪式，越自然越好；嫌烦的话用户会说。

# 什么是碎片

碎片是**任何可能活到最终文章里的文本**。入盘标准只有一条：**作者自己读得懂**——看到时能想起它在说什么。它不必定义术语、不必面向冷读者、不必自成论证。该问的是「这是一段好文字吗？」，不是「这是一个自洽的论证吗？」

碎片刻意混杂。以下都算：

- **锐句**：想找地方安放、还不知道放哪的一句锋利的话。
- **带论证的断言**：一个主张，附一行理由。
- **小插曲（vignette）**：发生过的一件事、一段代码、一个场景、一个类比。
- **半成品想法**：「关于 X 有点像 Y 的感觉，以后再想清楚。」
- **引语 / 对话 / 听来的话**：一句原话、一段对话、一句偶然听到的话。
- **凭感觉聚簇的观察**：一组说不上为什么、但直觉上该待在一起的观察。
- **抱怨 / 自白 / punchline**。
- **领词（leading word）**：一个能承载全篇的紧凑隐喻或造词——用一个词给整个想法命名，就像 tracer bullets（曳光弹）之于 tracer-bullet 式开发、fog of war（战争迷雾）之于那个模式。

## 领词：最值钱的碎片

领词是承重墙：在探索阶段命中一个对的领词，它会在日后牵着结构、过渡、标题走，让整个成文阶段持续受益。因此，**当对话反复绕着同一个想法打转时，主动推一把——为这个想法造一个词**。

原型是**小说家的日记**：多年不成结构地随手记下各种「注意到的东西」，日后从中挖出原材料。碎片就是那些注意到的东西。

# 文件格式

所有碎片追加进**同一个** markdown 文件。用户没给路径时，问一次存在哪，之后整个会话记住它。

首次写入时，文件顶部只放一个 H1 工作标题（以后可改），别的什么都不要：无元数据、无目录、无日期。此后碎片按追加顺序排列，之间用单独一行的 `---` 分隔；正文内不加标题、不打标签、不排序。

```markdown
# 工作标题

第一条碎片在这里。

可以有好几段，也可以包含列表、代码、引语——碎片本来长什么样
就保持什么样。

---

第二条碎片。

---

> 用户想留下的一句引语。

对它的一句反应。

---

- 一组彼此相关的观察
- 凭感觉聚在一起
- 直觉上想待在彼此旁边
```

# 写作节奏纪律

- **从用户说的第一句话就开始捕捉**，包括最初那句请求本身。
- **碎片不限来自谁**：用户说的、或追问过程中自己冒出来的，都记。
- **静默追加**：每条碎片落盘不必请示，顺口提一句「记下了」即可，绝不用保存确认打断对话。
- **每次写盘前先重读盘上文件**：用户可能在两轮之间编辑、重排、删除过碎片，必须保留他们的改动；永远只追加，绝不整文件覆写。
- **改碎片是一等指令**：用户随时可以说「删掉最后一条」「把那条改得更锐」「把这两条合并」，立即照办——这类指令允许原地改写对应片段。

# 借口 vs 现实

| 借口 | 现实 |
|---|---|
| 「等想清楚结构再动笔攒料」 | 攒料恰恰不需要结构；先攒后想，才攒得到料 |
| 「碎片必须自成论证才有价值」 | 作者读得懂就有价值；论证是成文阶段的事 |
| 「这想法还不成熟，不记了」 | 半成品想法正是碎片的主力形态，记下来以后再成熟 |
| 「先定个大纲，碎片往里填」 | 阶段化、大纲化会把探索挤死；那是 write-beats / write-shape 的活 |
| 「这话太口语，配不上文章」 | 引语、听来的话、抱怨、punchline 都是一等素材 |
| 「追问这么细，用户会烦」 | 追问是本件的发动机；静默追加并不打扰，用户烦了会说 |

# 红线自查

写盘前逐条核对，任何一条不过即停：

1. 是否出现了阶段划分、大纲或文章结构？（本件禁止一切强加结构）
2. 入盘标准是「作者读得懂」，还是在用「自成论证」筛掉好碎片？
3. 是否覆写、重排或丢掉了用户在盘上改过的内容？
4. 用户说「删 / 改得更锐 / 合并」时，是否当成一等指令照办了？
5. 对话反复绕同一个想法时，是否推过造词（领词）？
6. 碎片正文里是否混进了标题、标签或排序动作？

# 交接

攒到用户开始谈「怎么组织」「成文」时，停在本件边界：碎片文件原样留给用户，exploit 阶段交给 write-beats / write-shape。不确定该进体系里哪件技能时，见 meta-skill-router。
